# Reproducibility Guide

## 1. Purpose

This document explains how another user can reproduce the Medical AI Capstone prototype on a clean machine.

The project is designed to run locally using Python 3.11 and a virtual environment.

Docker is not required for the current reproducibility workflow.

---

## 2. System Requirements

Recommended environment:

- Windows 10 or Windows 11
- Python 3.11
- Git
- VS Code or another Python IDE
- Internet connection for package installation

The project was developed and tested using:

- Python 3.11.9
- PyTorch CPU execution
- FastAPI
- Streamlit
